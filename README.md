# 🌿 Datagronomy

## 🚀 Funcionalidades principales

### **1. Autenticación y Roles**  
- **Login seguro** con hash SHA-256.  
- **Roles diferenciados**:  
  - *Administrador*: Acceso total.  
  - *Granjero*: Solo módulos productivos.  

### **2. Gestión de Animales**  
- **Cerdas**:  
  - Registro por estado (vacia/gestante/lactancia).  
  - Historial reproductivo.  
- **Lechones**:  
  - Control de camadas (fecha, raza, lote).  
- **Semen**:  
  - Trazabilidad (origen, raza, fecha de adquisición).  

### **3. Procesos Clave**  
- **Montas**:  
  - Programación de inseminaciones.  
  - Cálculo automático de fecha probable de parto.  
- **Partos**:  
  - Registro de nacimientos (machos/hembras/muertos).  
  - Vinculación a cerda madre y lote.  

### **4. Inventario**  
- **Alimento**:  
  - Movimientos (entradas/salidas).  
  - Stock actualizado por tipo y lote.  

### **5. Comercial**  
- **Clientes**:  
  - Registro de datos y contactos.  
- **Ventas**:  
  - Facturación por peso (kilos) o unidades.  
  - Historial por cliente.  

### **6. Lotes y Corrales**  
- Creación y asignación de animales.  
- Descripción de características (ubicación, capacidad).  

---

### **Módulos Adicionales**  
- **Reportes básicos**:  
  - Producción (partos/ventas).  
  - Inventario (alimento/semen).  
- **Interfaz intuitiva**:  
  - Adaptada a dispositivos de escritorio.  

---

## 🛠️ Tecnologías utilizadas

- **Python** con Tkinter – Libreria grafica.
- **Mysql** – Base de datos local para almacenar informacion de aplicacion.
